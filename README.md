# Bilge

A web application for exploring universities, scholarships, and ORT preparation resources.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

## Features

- University directory and search
- Scholarship information
- ORT exam preparation materials
- Multi-language support
- Responsive design

## Tech Stack

- React
- Vite
- JavaScript
